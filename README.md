## 📂 Java Basics

Each Java class is kept in a separate file, and the **class name corresponds to the file name**.

### `JavaBasics`

Covers the fundamental concepts of Java:

* Printing output using `System.out.print()` and `System.out.println()`
* Variables and assigning values
* Changing and assigning variable values
* Primitive data types:

  * `byte`
  * `short`
  * `char`
  * `boolean`
  * `int`
  * `long`
  * `float`
  * `double`
* Non-primitive data types:

  * `String`
  * Arrays
  * Classes
  * Objects
  * Interfaces
* Basic arithmetic operations
* Addition of two numbers

### `JavaBasics2`

Introduces **user input in Java** using the `Scanner` class.

Covers:

* Creating a `Scanner` object
* Taking String input using `next()`
* Taking String input with spaces using `nextLine()`
* Taking integer input using `nextInt()`
* Taking floating-point input using `nextFloat()`
* Taking double input using `nextDouble()`
* Taking boolean input using `nextBoolean()`
* Basic input and output programs

### `JavaBasics3`

Introduces basic calculations and mathematical expressions in Java.

Covers:

* Taking numerical input from the user
* Addition of two numbers
* Using arithmetic expressions
* Calculating the area of a circle
* Using `float` values
* Using constants such as π (`3.14`)
* Basic string concatenation with variables
* Closing the `Scanner`
