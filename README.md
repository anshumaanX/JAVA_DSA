## 📂 Java Basics

Each Java class is stored in a separate file.

**The class name tells you the corresponding file name.**

For example:

`JavaBasics` → `JavaBasics.java`

---

### `JavaBasics.java`

Introduces the basic building blocks of Java.

Topics covered:

- Printing output using `System.out.print()` and `System.out.println()`
- Variables
- Assigning and changing variable values
- Primitive data types:
  - `byte`
  - `short`
  - `char`
  - `boolean`
  - `int`
  - `long`
  - `float`
  - `double`
- Non-primitive data types
- Basic arithmetic operations
- Addition of two numbers

---

### `JavaBasics2.java`

Introduces taking input from the user using the `Scanner` class.

Topics covered:

- Creating a `Scanner` object
- Taking String input using `next()`
- Taking complete-line String input using `nextLine()`
- Taking integer input using `nextInt()`
- Taking float input using `nextFloat()`
- Taking double input using `nextDouble()`
- Taking boolean input using `nextBoolean()`
- Basic input and output

---

### `JavaBasics3.java`

Introduces basic calculations and mathematical expressions.

Topics covered:

- Taking numerical input from the user
- Adding two numbers
- Arithmetic expressions
- Calculating the area of a circle
- Using `float` values
- Using π (`3.14`)
- String concatenation with variables
- Closing the `Scanner`

---

### `JavaBasics4.java`

Introduces **Type Conversion** in Java.

Topics covered:

- What type conversion means
- Implicit conversion
- Widening conversion
- Converting smaller compatible data types into larger data types
- Basic type conversion order:
  - `byte → short → int → long → float → double`
- Understanding why some conversions are valid and others are not
- Type conversion while taking input using `Scanner`
